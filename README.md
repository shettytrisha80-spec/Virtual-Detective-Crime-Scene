# Virtual Detective Crime Scene

## About the Project
Virtual Detective Crime Scene is an interactive 3D crime investigation game developed using Godot Engine.

## Features
- Interactive 3D crime scene environment
- Player movement and exploration
- Evidence investigation and interaction
- Crime investigation gameplay

## Technologies Used
- Godot Engine
- GDScript
- 3D Game Development

## How to Run
1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open Godot Engine.
4. Import the project by selecting the `project.godot` file.
5. Run the project.
